# file2GPT

通用状态栏 SillyTavern 扩展。

## 怀孕后续反应（1.2.0）

在状态栏的 **设置 → 功能设置 → 怀孕后续反应** 中启停，默认开启，设置自动保存。

- 开启时，生成请求会自动携带一条常驻世界书规则，覆盖事后情绪、补救行动、风险观察及孕期到产后的七个阶段。
- 规则允许正文根据已结算的阶段，在普通日常中自然引入尚未记录的新线索，随后由数据库记住；人物的认知仍依剧情推进。
- 关闭开关后，后续生成不再携带该规则。禁用整个扩展也停止注入；规则不写入世界书文件或角色卡，不留下持久条目。
- 数据库插件继续负责召回、填表和受孕结算，本开关只控制后续反应规则。

更新扩展文件后刷新酒馆，无需手动添加世界书条目。需使用支持 `WORLDINFO_ENTRIES_LOADED` 事件的酒馆；不支持时设置会显示“暂不可用”。

配套的 [状态栏数据库模板.json](状态栏数据库模板.json) 已补充主角、NPC 两张表的填写说明。新聊天可使用此模板；已有聊天只更新两张表的“后续反应承接”说明即可，不需要清空表数据或重置原有受孕结果。其他前端字段适配不在本次改动范围内。
